# Security Policy

We take the security of **FinPilot AI** seriously. If you believe you have found
a security vulnerability, please report it responsibly using the process below.

---

## Supported Versions

Security updates and patches are currently handled for the latest mainline
release of FinPilot AI.

| Version | Supported          |
| ------- | ------------------ |
| latest main | :white_check_mark: |
| older releases | :x:                |

We strongly recommend using the latest stable version and keeping dependencies
updated to reduce exposure to known issues.

---

## Reporting a Vulnerability

**Please do not open a public GitHub issue for security-related reports.**

To report a vulnerability:

1. **Email us:** Send a detailed report to
   **<shivamshashank@users.noreply.github.com>**.
2. **GitHub Security Advisory:** If you have access, you may also open a private
   security advisory from the repository's Security tab on GitHub.

### What to Include in Your Report

- a description of the vulnerability and its potential impact
- steps to reproduce the issue, including relevant payloads or environment
  details
- suggestions for mitigation or a proposed fix

---

## Response Process

1. **Acknowledgment:** We will acknowledge receipt of your report as soon as
   possible.
2. **Evaluation:** We will investigate the issue, determine severity, and
   assess the appropriate remediation steps.
3. **Fix and Disclosure:** Once a fix is verified, we will release it and
   coordinate a public advisory if appropriate.

Thank you for helping keep FinPilot AI secure and reliable.
